FACULTY PHOTO (nithya.jpg)
--------------------------
The faculty card on index.html is already wired to display:

    assets/nithya.jpg

Until that file exists it automatically falls back to the initials "NK".
To show the real photo, save it here as nithya.jpg. The photo is available on
her SRM faculty profile:

    https://www.srmist.edu.in/faculty/dr-nithyakalyani-k-2/

Open the page, right-click her photo -> "Save image as..." -> save it into this
folder as  nithya.jpg  (a roughly square image, ~300px+ wide, looks best).

The header logos fall back to a 🧠 mark + text automatically if missing.
